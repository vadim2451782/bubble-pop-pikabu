# Лопни пузыри — сборка для Пикабу Игр

Игра-стрелялка шариками, собранная для публикации на платформе
[Пикабу Игры](https://games.pikabu.ru/).

Это **отдельная сборка**, исходная PWA-версия живёт в репозитории
`bubble-pop` и не менялась.

## Что внутри

- `index.html` — игра, подключающая SDK платформы
  (`https://games.pikabu.ru/sdk/sdk.js`), флаг `window.__PIKABU__ = true`;
- `js/platform.js` — мост к SDK: инициализация, `gameStarted()`,
  rewarded-реклама, облачные сохранения;
- `js/`, `css/`, `icons/` — сама игра;
- `.nojekyll` — чтобы GitHub Pages отдавал файлы как есть.

## Отличия от PWA-версии

| | PWA (`bubble-pop`) | Пикабу (этот репозиторий) |
|---|---|---|
| Манифест и Service Worker | есть | нет |
| Экран «установите на iPhone» | есть | нет |
| Плашка «PWA · работает офлайн» | есть | нет |
| Название на экране меню | Bubble Pop | Лопни пузыри |
| SDK платформы | нет | да |
| Rewarded-реклама в магазине | нет | да |
| Облачные сохранения | нет | да |
